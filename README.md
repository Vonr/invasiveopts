# Invasive Optimizations

![Logo](https://github.com/Vonr/invasiveopts/raw/1.21/logo.png)

Invasive optimizations for other mods. If you experience any issues, disable this mod first!

Most of the optimizations implemented are Merge Requests (aka Pull Requests) that I opened but have yet to be merged.

Current optimizations:
- Botany Pots
